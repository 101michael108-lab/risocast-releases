# Risocast downloads

Installers for [Risocast](https://risocast.com) — it logs the music you play on
your computer and phone, and finds people with the same taste.

**Windows:** [Download the latest installer](https://github.com/101michael108-lab/risocast-releases/releases/latest/download/Risocast-Setup.exe)

The source lives in a private repository; this one only hosts release files.
